# BUG-001 — Non-existing ID closes connection

## Summary

`GET /music/{id}` closes the connection when requesting a non-existing resource instead of returning an appropriate HTTP error response.

## Affected Test Case

TC-002

## Endpoint

`GET /music/999999`

## Steps to Reproduce

1. Start the application.
2. Send:

```bash
curl -i localhost:8000/music/999999
```

## Expected Result

```text
404 Not Found
```

The API should return a valid HTTP error response.

## Actual Result

```text
Error: socket hang up
```

The server continues running and accepts subsequent requests.

## Severity

Medium

## Priority

Medium

## Status

Open
