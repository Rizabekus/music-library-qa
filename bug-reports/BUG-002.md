# BUG-002 — Invalid string ID causes 500 Internal Server Error

## Summary

`GET /music/{id}` returns `500 Internal Server Error` when a string is provided instead of a numeric ID.

## Affected Test Case

TC-005

## Endpoint

`GET /music/abc`

## Steps to Reproduce

1. Start the application.
2. Send:

```bash
curl -i localhost:8000/music/abc
```

## Expected Result

```text
400 Bad Request
```

The API should reject the invalid ID format.

## Actual Result

```text
500 Internal Server Error
```

## Severity

Medium

## Priority

High

## Status

Open
