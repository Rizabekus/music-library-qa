# BUG-003 — Extremely large ID causes 500 Internal Server Error

## Summary

`GET /music/{id}` returns `500 Internal Server Error` when an extremely large numeric ID is provided.

## Affected Test Case

TC-006

## Endpoint

`GET /music/999999999999`

## Steps to Reproduce

1. Start the application.
2. Send:

```bash
curl -i localhost:8000/music/999999999999
```

## Expected Result

The API should return an appropriate client error, such as `400 Bad Request`, or `404 Not Found` if the ID is syntactically valid but does not exist.

## Actual Result

```text
500 Internal Server Error
```

## Severity

Medium

## Priority

High

## Status

Open
