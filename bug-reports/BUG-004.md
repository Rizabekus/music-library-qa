# BUG-004 — POST with invalid data type causes 500 Internal Server Error

## Summary

`POST /music` returns `500 Internal Server Error` when a field contains an invalid data type.

## Affected Test Case

TC-013

## Endpoint

`POST /music`

## Valid Request Body

```json
{
  "group": "hello",
  "song": "world"
}
```

## Invalid Request Body

```json
{
  "group": 12345,
  "song": "world"
}
```

## Steps to Reproduce

1. Start the application.
2. Send the POST request with the invalid data type.

```bash
curl -i -X POST http://localhost:8000/music \
  -H "Content-Type: application/json" \
  -d '{"group":12345,"song":"world"}'
```

## Expected Result

```text
400 Bad Request
```

## Actual Result

```text
500 Internal Server Error
```

## Severity

Medium

## Priority

High

## Status

Open
