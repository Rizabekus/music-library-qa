# BUG-005 — Malformed JSON causes 500 Internal Server Error

## Summary

`POST /music` returns `500 Internal Server Error` when malformed JSON is submitted.

## Affected Test Case

TC-018

## Endpoint

`POST /music`

## Request Body

```json
{
  "group": "hello",
  "song": "world"
```

The closing `}` is intentionally missing.

## Steps to Reproduce

1. Start the application.
2. Send a POST request with malformed JSON.

```bash
curl -i -X POST http://localhost:8000/music \
  -H "Content-Type: application/json" \
  -d '{"group":"hello","song":"world"'
```

## Expected Result

```text
400 Bad Request
```

## Actual Result

```text
500 Internal Server Error
```

## Severity

Medium

## Priority

High

## Status

Open
