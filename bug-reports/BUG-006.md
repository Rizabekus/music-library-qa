# BUG-006 — Empty POST body causes 500 Internal Server Error

## Summary

`POST /music` returns `500 Internal Server Error` when the request body is empty.

## Affected Test Case

TC-019

## Endpoint

`POST /music`

## Steps to Reproduce

1. Start the application.
2. Send a POST request without a request body.

```bash
curl -i -X POST http://localhost:8000/music \
  -H "Content-Type: application/json"
```

## Expected Result

```text
400 Bad Request
```

## Actual Result

```text
500 Internal Server Error
```

## Severity

Medium

## Priority

High

## Status

Open
