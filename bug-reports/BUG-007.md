# BUG-007 — PUT non-existing resource returns 400 instead of 404

## Summary

`PUT /music/{id}` returns `400 Bad Request` when attempting to update a non-existing resource instead of returning `404 Not Found`.

## Affected Test Case

TC-022

## Endpoint

`PUT /music/999999`

## Request Body

```json
{
  "group": "hello",
  "link": "https://example.com",
  "release_date": "2024-01-01",
  "song": "world",
  "text": "QA test"
}
```

## Steps to Reproduce

1. Start the application.
2. Send:

```bash
curl -i -X PUT http://localhost:8000/music/999999 \
  -H "Content-Type: application/json" \
  -d '{"group":"hello","link":"https://example.com","release_date":"2024-01-01","song":"world","text":"QA test"}'
```

## Expected Result

```text
404 Not Found
```

## Actual Result

```text
400 Bad Request
```
