# BUG-008 — PUT with invalid data type causes 500 Internal Server Error

## Summary

`PUT /music/{id}` returns `500 Internal Server Error` when a field contains an invalid data type.

## Affected Test Case

TC-027

## Endpoint

`PUT /music/1`

## Valid Request Body

```json
{
  "group": "hello",
  "link": "https://example.com",
  "release_date": "2024-01-01",
  "song": "world",
  "text": "QA test"
}
```

## Invalid Request Body

```json
{
  "group": 12345,
  "link": "https://example.com",
  "release_date": "2024-01-01",
  "song": "world",
  "text": "QA test"
}
```

## Steps to Reproduce

1. Start the application.
2. Send the PUT request with the invalid data type.

## Expected Result

```text
400 Bad Request
```

## Actual Result

```text
500 Internal Server Error
```

## Severity

Medium

## Priority

High

## Status

Open
