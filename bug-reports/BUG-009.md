# BUG-009 — DELETE non-existing resource returns 400

## Summary

`DELETE /music/{id}` returns `400 Bad Request` when attempting to delete a non-existing resource.

## Affected Test Case

TC-032

## Endpoint

`DELETE /music/999999`

## Steps to Reproduce

1. Start the application.
2. Send:

```bash
curl -i -X DELETE http://localhost:8000/music/999999
```

## Expected Result

A defined error response for a non-existing resource, typically:

```text
404 Not Found
```

## Actual Result

```text
400 Bad Request
```

## Severity

Low

## Priority

Medium

## Status

Open
