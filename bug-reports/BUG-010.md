# BUG-010 — Repeated DELETE request returns 400

## Summary

Deleting the same resource twice results in `400 Bad Request` on the second request.

## Affected Test Case

TC-036

## Endpoint

`DELETE /music/{id}`

## Steps to Reproduce

1. Delete an existing resource:

```bash
curl -i -X DELETE http://localhost:8000/music/1
```

2. Send the same request again:

```bash
curl -i -X DELETE http://localhost:8000/music/1
```

## Expected Result

The second request should return a defined response for an already deleted resource, according to the API specification.

## Actual Result

```text
400 Bad Request
```

## Severity

Low

## Priority

Low

## Status

Open
